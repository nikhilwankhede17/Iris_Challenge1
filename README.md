# Iris Challenge 1 — Customer Churn Prediction

A machine learning project to predict customer churn for a telecom company.

## Problem Statement
Using a dataset of 5,000 customers, build a model that predicts whether a customer will cancel their subscription.

## Approach
- Exploratory Data Analysis (EDA)
- Data cleaning & preprocessing
- Logistic Regression (core model)
- Random Forest (bonus comparison)
- Evaluation: Accuracy, Precision, Recall, F1, ROC-AUC, Confusion Matrix
- Class imbalance handling
- Feature importance
- Streamlit prediction app (bonus)

## Setup

### Requirements
- Python 3.11+

### Install dependencies
```bash
pip install -r requirements.txt
```

### Run the notebook / script
```bash
python churn_prediction.py
```

### Run the Streamlit app (bonus)
```bash
streamlit run app.py
```

## Dataset
Place `churn_data.csv` in the project root directory (not tracked by git).
